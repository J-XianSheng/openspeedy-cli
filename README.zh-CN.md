# 🚀 特性
- 快捷变速
- 命令行界面，无 GUI / WebView / 前端构建依赖
- 同时可以支持x86和x64平台进程
- 无内核侵入性，Ring3层Hook，不破坏系统内核


# 💾 安装

## 下载（推荐）

从 [GitHub Releases](https://github.com/J-XianSheng/openspeedy-cli/releases)
下载最新的 `OpenSpeedy-<版本>-cli.zip`，解压后把 5 个文件放在同一目录。

## 从源码构建

``` powershell
cargo build --release
```

两种方式得到的运行时文件相同（构建会复制到 `src-tauri\target\release\`）：

| 文件 | 用途 |
|------|------|
| `openspeedy.exe` | 命令行主程序 |
| `bridge64.exe` / `bridge32.exe` | 辅助进程（按需启动） |
| `speedpatch64.dll` / `speedpatch32.dll` | 注入游戏的时间 API Hook DLL |

把这 5 个文件放到任意目录，运行 `openspeedy.exe help` 即可。

# 💻 操作系统要求
- OS: Windows10 以上
- 平台：x86（32位） 和 x64 （64位）
- 编译环境：[Rust](https://www.rust-lang.org/) · [CMake](https://cmake.org/) · [Visual Studio](https://visualstudio.microsoft.com/)（含 C++ 桌面开发工作负载）


# 📝 使用说明

``` powershell
# 1. 找到目标游戏进程（过滤词匹配 名称 / PID / 窗口标题）
openspeedy list game

# 2. 注入并启用变速 —— 支持 PID 或精确进程名（32/64 位自动识别）
openspeedy inject 1234          # 或：openspeedy inject game.exe

# 3. 设置速度倍率 —— 对所有已注入进程立即生效
openspeedy speed 2              # 2 为双倍速、0.5 为半速（范围 0.01 – 1000）
```

| 命令 | 说明 |
|------|------|
| `list [过滤词] [-a]` | 列出进程（`-a` 含系统进程） |
| `inject <PID\|名称>` | 注入并启用变速 |
| `enable <PID\|名称>` / `disable <PID\|名称>` | 恢复 / 暂停变速 |
| `speed <倍率>` | 设置倍率（0.01 – 1000） |
| `status [PID\|名称]` | 查看当前倍率 / 注入状态 |
| `stop` | 终止后台 bridge 进程 |

注意事项：

- **只有被注入的进程会变速** —— 想只加速某个游戏，就只 inject 它；倍率是全局值，会应用到所有已注入的进程。
- `inject` / `enable` / `disable` / `status` 按进程名**精确匹配**（不区分大小写、`.exe` 可省，同名进程全部处理）；`list` 的过滤词是子串匹配 —— 先用 `list` 拿到准确名称。
- 倍率保存在 `%APPDATA%\OpenSpeedy\cli-state.json`，下次命令自动恢复（因此先 `speed` 后 `inject` 也能直接生效）。
- 游戏以管理员身份运行时，工具也需要用管理员终端运行，否则注入会被拒绝；失败时查看可执行文件同目录的 `bridge64.exe.log` / `bridge32.exe.log`。
- 完整帮助见 `openspeedy help`。

# 🔧 技术原理

编译环境要求：
- [Rust](https://www.rust-lang.org/)
- [CMake](https://cmake.org/)
- [Visual Studio](https://visualstudio.microsoft.com/)（含 C++ 桌面开发工作负载）
- 可选（支持 32 位游戏）：`rustup target add i686-pc-windows-msvc`

编译命令：

``` powershell
cargo build --release
```

OpenSpeedy 通过 Hook 以下 Windows 系统时间函数来实现游戏速度调整：

|函数名	| 所属库 |	功能 |
|--------|----------|------------------|
|Sleep|user32.dll|线程休眠|
|SetTimer|user32.dll|创建基于消息的计时器|
|timeGetTime | winmm.dll	| 获取系统启动后经过的毫秒数 |
|GetTickCount | kernel32.dll	| 获取系统启动后经过的毫秒数 |
|GetTickCount64	| kernel32.dll	| 获取系统启动后经过的毫秒数(64位) |
|QueryPerformanceCounter |	kernel32.dll	| 高精度性能计数器 |
|GetSystemTimeAsFileTime |	kernel32.dll	| 获取系统时间 |
|GetSystemTimePreciseAsFileTime |	kernel32.dll	| 获取高精度系统时间 |
|SetWaitableTimer |	kernel32.dll	| 设置可等待定时器 |
|SetWaitableTimerEx |	kernel32.dll	| 设置可等待定时器(扩展) |

# ⚠️ 注意事项
- 本工具仅供学习和研究使用
- 部分在线游戏可能有反作弊系统，使用本工具可能导致账号被封禁
- 过度加速可能导致游戏物理引擎异常或崩溃
- 不建议在竞技类在线游戏中使用
- 开源产品不带数字签名，可能被杀毒软件误报
